# Git Testing Sandbox

Một kho lưu trữ (repository) nhỏ được tạo ra với mục đích thực hành, thử nghiệm và làm quen với các câu lệnh cũng như quy trình làm việc (workflow) của Git và GitHub.

---

##  Mục tiêu thử nghiệm
* Thực hành các lệnh cơ bản: `git init`, `git add`, `git commit`, `git push`.
* Thử nghiệm quản lý nhánh (Branching): tạo nhánh mới, chuyển nhánh và gộp nhánh (`git merge`).
* Tập xử lý xung đột mã nguồn (Conflict resolution).
* Cấu hình thông tin tài khoản cá nhân (`user.name`, `user.email`).

##  Công cụ sử dụng
* **Git Bash** (hoặc Terminal)
* **GitHub**
